## Objective
Implement Outbox Pattern for reliable event publishing

---

## Requirements

### 1. Create Outbox Table (DynamoDB)

pk: EVENT#<id>
status: PENDING | SENT

---

### 2. During template write:
- Save metadata
- Save outbox event (same transaction if possible)

---

### 3. Create Outbox Processor Lambda

- Reads pending events
- Publishes to EventBridge
- Marks as SENT

---

## Output

- Guaranteed event delivery
- No data inconsistency
